# Study Lock — Kids App Lock (Study to Unlock)

## How to run
1. Unzip, then Android Studio → File → Open → select the `StudyLock` folder.
2. Let Gradle sync (Studio downloads Gradle 8.7 and dependencies).
3. Connect a phone (USB debugging on) → Run ▶.
4. In the app: set a PIN → "Open Accessibility settings" → enable **Study Lock**.
5. Choose apps to lock, then open one of them — the quiz appears.
